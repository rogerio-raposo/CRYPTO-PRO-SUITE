# PCP-01 — Prospective Institutional Validation Shadow Test

**Status:** PRE-REGISTERED DIAGNOSTIC — NOT YET EXECUTED
**Origin:** QNT Exception Review / MGR-006
**Decision effect:** NONE in Run A unless a later methodological revision is explicitly approved and Run A is rerun as a separate version.

## Research question

Does the frozen PCP-01 Relationship Layer omit useful information when a highly credible institutional commitment materially increases the probability of future token capture before current token-level value transmission becomes observable?

## Anti-overfit rule

The diagnostic is not created to rescue QNT. It must be applied symmetrically to all 12 Run A assets using the same evidence cut and rules. Observed post-event price performance is excluded from diagnostic classification.

## Diagnostic dimensions

### IV — Institutional Validation
- IV0: none demonstrated
- IV1: exploratory / non-binding / generic
- IV2: concrete integration, selection, mandate, launch or deployment commitment
- IV3: systemically significant or unusually consequential institutional validation
- IND: insufficient evidence

### PM — Prospective Materialization
- PM0: conceptual / no committed deployment
- PM1: announced development / uncertain deployment
- PM2: committed implementation with identifiable path or timing
- PM3: live or recurring institutional operation
- IND

### PTC — Prospective Token-Capture Plausibility
- PTC0: no credible token pathway
- PTC1: speculative or indirect pathway
- PTC2: identifiable but not yet realized/material token pathway
- PTC3: current direct pathway; normally already represented by Economic Capture
- IND

## QNT shadow example

Using only pre-cut evidence: IV3 / PM2 / PTC1.

Interpretation: institutional validation is unusually strong; deployment has a concrete path and timing; token-level future capture remains weakly evidenced because current public payment terms allow USD and the TCH announcement specifies no QNT requirement.

This diagnostic would flag QNT for monitoring without converting Materiality FAIL into PASS.

## Possible outcomes after symmetric testing

1. Adds no distinct information → discard.
2. Useful only for monitoring → attach to Critical Event Watch.
3. Materially improves phenomenon coverage → propose a formal methodology revision and versioned rerun.
4. Overlaps existing constructs → refine anchors instead of adding a construct.

## Price quarantine

Price, return, market-cap change and volume spikes may be inspected only after diagnostic classification for ex-post validation research. They cannot assign IV, PM or PTC.
