## Evidence rules

- Tier 1 = primary protocol/project/foundation documentation or governance record.
- Tier 2 = direct issuer/institution/partner evidence.
- Same underlying event is not counted as multiple independent confirmations.
- Discovery-category evidence is excluded from construct confirmation.
- Negative/limiting evidence is retained.
