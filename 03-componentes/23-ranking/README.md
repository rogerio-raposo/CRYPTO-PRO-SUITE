# 23 — Ranking Institucional Simplificado

Documentação específica do Ranking Institucional Simplificado.

## Organização

- `metodologia/` — especificação normativa e documentos que definem como o Ranking funciona.
- `validacao/` — pilotos, testes, evidências de validação e decisões que sustentam a metodologia.

O Ranking permanece independente dos demais módulos. Narrative Opportunity é upstream e pertence à camada de rotação; construção de portfólio pertence ao CSE, não ao Ranking.
