# Microcaps — Metodologia

Área destinada à especificação normativa da submetodologia **Microcaps** do Ranking Institucional Simplificado.

O ciclo experimental pré-v1.0 de Microcaps foi encerrado. A consolidação normativa deve incorporar somente regras que sobreviveram aos pilotos, mantendo itens experimentais e backlog separados.
