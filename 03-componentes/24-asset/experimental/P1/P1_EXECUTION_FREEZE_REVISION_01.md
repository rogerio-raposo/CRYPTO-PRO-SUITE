## 1. Trigger

Before exposing the formal DEV Human Review package to the human reviewer, audit identified that reviewer-facing swing objects still contained:

- `method`;
- `profile_id`;
- `volatility_ref`.

Although profile containers were labeled only as `R01 ... R09`, these fields disclosed method/parameter identity or method-class information.

This violates Design Freeze Revision 03:

> reviewer-facing artifacts must expose aliases only and must not reveal detector method/profile identity.

The flawed reviewer-facing packages were therefore **not accepted as valid Human Review artifacts** and were not presented to the human reviewer.

## 2. Scope of Correction

The correction changes only reviewer-facing serialization.

For each exposed swing, the valid blinded payload now contains only:

- `kind`;
- `extremum_index`;
- `extremum_open_us`;
- `price`;
- `confirmation_index`;
- `confirmation_end_us`.

The export layer now recursively rejects reviewer packages containing prohibited identity keys:

- `method`;
- `profile_id`;
- `volatility_ref`;
- `detector`;
- `estimator`;
- `window`;
- `multiplier`;
- `percentage`.

No D1 detector, structural rule, metric, plateau rule, candidate identity, dataset, parameter or reference-band rule changed.
