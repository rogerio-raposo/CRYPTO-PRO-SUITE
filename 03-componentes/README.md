# Volume III — Componentes

Documentação dos módulos funcionais do CRYPTO PRO SUITE.

## Estrutura

- `20-macro/` — CRYPTO MACRO PRO.
- `21-rotation/` — Capital Rotation PRO e componentes de rotação.
- `22-institutional/` — componentes institucionais.
- `23-ranking/` — Ranking Institucional Simplificado.
- `24-asset/` — análise por ativo.
- `25-cse/` — Crypto Strategy Engine (CSE).

Cada componente pode manter subpastas próprias para metodologia, validação, especificações e registros técnicos quando necessário.
