# CRYPTO PRO SUITE – Arquitetura v1.0

## Objetivo
A **CRYPTO PRO SUITE** é um conjunto de módulos independentes de apoio à decisão para análise do mercado de criptoativos.

Seu propósito é reduzir a incerteza do processo decisório por meio de diferentes perspectivas complementares. Nenhum módulo, isoladamente, determina uma decisão de investimento.

## Princípios
1. Cada módulo possui uma missão específica.
2. Os módulos são independentes.
3. Podem ser utilizados isoladamente ou em conjunto.
4. A convergência entre módulos aumenta a confiança na análise.
5. O objetivo é antecipar movimentos de fluxo de capital.
6. As conclusões devem ser sustentadas por indicadores objetivos sempre que possível.

## Módulos
### CRYPTO MACRO PRO
Pergunta: **Por que** o ambiente favorece ou não os ativos de risco?

### CAPITAL ROTATION PRO
Pergunta: **Para onde** o capital global está migrando?

### INSTITUTIONAL FLOW PRO
Pergunta: **Quem** está movimentando o capital?

### Ranking Institucional Simplificado
Pergunta: **Quais** ativos têm maior probabilidade de capturar o próximo fluxo institucional?
Mantém sua metodologia original e independente.

### ASSET PRO
Pergunta: **Quando** um ativo apresenta uma oportunidade técnica?
