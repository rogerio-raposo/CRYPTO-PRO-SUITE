## Persistence rule

The authoritative reconstruction unit is one independently traceable historical event. Each detailed RH must preserve, at minimum:

- RH ID
- title
- event date / temporal precision
- object/category
- description
- historical state trajectory
- markers, where applicable
- confidence (C0–C4)
- primary source
- corroborating sources
- relations to other RHs
- documentary/project impact
- current state
- observations
